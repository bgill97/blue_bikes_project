This is a personal data project I have put together on blue bikes usage in the Greater Boston area.

Blue Bikes are shareable bikes stationed around the city that riders can "rent" for short periods of time.

To run this script, please download the blue bikes ridership data from May 2025. That can be found here: https://s3.amazonaws.com/hubway-data/index.html. This will download a zip file, and inside is a CSV. This CSV contains the source ridership data.

Bring the CSV file to your working directory to run the script.

Enjoy!
